# 人物与世界备忘

本页只根据公开简介整理，供续写时对齐气质与背景。这里没有原作章节摘录，也不补写未公开的剧情。若与你实际读到的进度不一致，以 [continuity.md](continuity.md) 里自己填写的记录为准。

## 时代与地点

- 时间：1991 年
- 地点：日本北海道

写生活场景时保留这个年代的信息方式：当面交谈、电话、报纸、学校告示和口耳相传。智能手机与即时网络不属于这个时代。北海道的气候、校园和城镇日常可以提供生活质感；不必把每一章写成地方介绍。

## 人物

### 七原武

- 穿越而来的少年。
- 处事务实，观察敏锐。
- 有诡计师、骗子一类的背景，会看穿场面，也会利用信息差。
- 对外常常以灵媒的身份活动。
- 幽默偏冷、偏干，以吐槽和拆台为主，少做热情演说。

### 清见琉璃

- 自封的侦探少女。
- 认真，行动上容易笨拙。气质接近藏狐：有一股要查清楚的气势，关键步骤却常常差一点。
- 想成立演绎推理社团。

两人一起行动时，七原武负责观察、补位和拆穿，清见琉璃负责把「要查」这件事认真扛起来。任何一方都不必写成全能，也不必写成纯粹的笑料。

## 基调

- 日式轻小说式的轻推理，加上日常喜剧。
- 以单元案件为主。一章收束一个小事件，或数章收束一个小谜题，都可以。
- 对话比长段说明更重要。
- 日常生活、相处与食物，往往和案件同样重要。吃饭、闲聊、社团筹备可以与异常并列，不必为了「像推理」而删掉。

公开简介之外的人物关系、已发生案件和具体校园细节，留到 [continuity.md](continuity.md) 由阅读进度补上。未记录的内容，续写时保持克制。
