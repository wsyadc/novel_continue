# 《我可不是侦探》同人续写工作区

本仓库是网络小说《我可不是侦探》（作者：海底漫步者）的非官方同人续写工作区。用途是在公开设定与人物气质之内，按章节继续写下去，并留下衔接记录，方便以后一章一章往下接。

## 声明

- 本仓库为非官方同人创作，与原作者、连载平台及其他权利方无关。
- 《我可不是侦探》及其角色、世界观的原创权利归 **海底漫步者** 所有。
- 本仓库不收录原作章节正文。续写使用原创情节，人名与背景只作同人衔接。
- 若权利方要求撤下相关内容，应删除对应文件并停止传播。

## 章节如何组织

续写正文放在 [`chapters/`](chapters/README.md)。一篇一文件，文件名用四位序号加短标题：

```text
chapters/0001-标题.md
chapters/0002-标题.md
```

每个文件开头写元数据，再写正文：

- **衔接自**：这一章从哪里接上
- **本章摘要**：用自己的话概括本章
- **正文**：原创续写

序号是本仓库的续写顺序，不是原作章节号。命名与模板见 [chapters/README.md](chapters/README.md)。

配套文档：

| 文件 | 用途 |
| --- | --- |
| [docs/setting.md](docs/setting.md) | 依公开简介整理的时代、人物与基调，不含原作正文 |
| [docs/style-guide.md](docs/style-guide.md) | 续写时的文风、一致性与版权边界 |
| [docs/continuity.md](docs/continuity.md) | 进度、关系与待续衔接点，由维护者以后填写 |

## 按章续写

每次围绕一个衔接点推进：

1. 阅读 [docs/continuity.md](docs/continuity.md)，确认当前读到哪里、最后情节摘要，以及待续衔接点。
2. 对照 [docs/setting.md](docs/setting.md) 与 [docs/style-guide.md](docs/style-guide.md)，核对时代、人物和语气。
3. 在 `chapters/` 按递增序号新建下一章，文首写清「衔接自」和「本章摘要」。
4. 写完后，把本章摘要和章末状态回写到 `docs/continuity.md`。
5. 提交说明里写清本章接了哪一处、推进了什么。

协作时尽量小步提交：一章，或一组紧密相关的修订，做一次提交。改设定备忘或文风规则时单独提交，并在说明里写清原因。

`docs/continuity.md` 目前是空模板。开始续写前先填「读到章节/案卷」和「待续衔接点」，避免新章节悬空。

## 写作边界

- 不在本仓库粘贴原作章节、长段对白或大段复述。
- 新章节以原创案件、日常、对话和相处为主，人物行为与已记录设定保持一致。
- 没有把握的原作细节先记在 `docs/continuity.md`，确认之前不当作既定事实写入正文。
