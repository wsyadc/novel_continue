# 章节目录

续写正文放在本目录，一章一个 Markdown 文件。本目录的序号只表示本仓库的写作顺序。

## 命名

使用四位序号加短标题，序号递增：

```text
0001-标题.md
0002-标题.md
0003-另一个短标题.md
```

- 序号从 `0001` 起，不足四位时左侧补零。
- 标题用简短中文。词语之间需要断开时使用连字符 `-`。
- 标题自拟，不必沿用原作章节名。

## 文件开头

每个章节文件先写元数据，再写正文：

```markdown
# 章节标题

- 衔接自：
- 本章摘要：

## 正文

（从这里开始写。摘要用自己的话，不粘贴原作段落。）
```

- **衔接自**：上一章文件名，或 [docs/continuity.md](../docs/continuity.md) 里记录的待续衔接点。本仓库第一次开写时，写明「自进度记录起笔」，并在 continuity 里记下对应进度。
- **本章摘要**：五句以内，供下一章和进度页使用。写清人物做了什么、案件或日常推进到哪里。
- **正文**：原创续写。对话可以多，案件与吃饭、相处、社团事务可以并行。

写完一章后，把摘要和章末状态回写到 [docs/continuity.md](../docs/continuity.md) 的「最后情节摘要」和「待续衔接点」。
